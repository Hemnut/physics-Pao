4. มวลพร่อง (Mass Defect: Δm) & พลังงานยึดเหนี่ยว (BE)

เมื่อนิวคลีออนอิสระมารวมตัวกันเป็นนิวเคลียส มวลรวมจะหายไปบางส่วนกลายเป็นพลังงานยึดเหนี่ยวตามสมการ E = mc²

มวลพร่อง (Mass Defect: Δm)
Δm = [Z · mp + (A - Z) · mn] - Mnucleus
พลังงานยึดเหนี่ยว (Binding Energy: BE)
BE = Δm (u) × 931.5 MeV
1 u = 931.5 MeV / c² = 1.66 × 10-27 kg
ความเสถียรของนิวเคลียส (Nuclear Stability): นิวเคลียสจะเสถียรมากหรือน้อยพิจารณาจาก พลังงานยึดเหนี่ยวต่อนิวคลีออน (BE / A) ยิ่งมีค่าสูง ยิ่งเสถียร นิวเคลียสของ เหล็ก (5626Fe) มีค่า BE/A สูงที่สุดประมาณ 8.8 MeV/nucleon ซึ่งมีความเสถียรสูงสุดในธรรมชาติ

5. ปฏิกิริยานิวเคลียร์: ฟิชชัน vs ฟิวชัน & พลังงานปฏิกิริยา (Q)

ฟิชชัน (Nuclear Fission)

นิวเคลียสหนักแตกตัวเป็นนิวเคลียสขนาดกลาง 2 ตัว พร้อมนิวตรอนเร็ว 2-3 ตัว และพลังงานมหาศาล ก่อให้เกิด ปฏิกิริยาลูกโซ่ (Chain Reaction) เช่นในเครื่องปฏิกรณ์นิวเคลียร์

23592U + 10n → 14156Ba + 9236Kr + 3(10n) + Q
ฟิวชัน (Nuclear Fusion)

นิวเคลียสเบาหลอมรวมเป็นนิวเคลียสหนักขึ้น เกิดที่อุณหภูมิและความดันสูงมาก (บนดวงอาทิตย์ / ระเบิดไฮโดรเจน) ให้พลังงานต่อนิวคลีออนสูงกว่าฟิชชัน และไม่มีกากกัมมันตรังสีอันตราย

21H + 31H → 42He + 10n + 17.6 MeV
การคำนวณพลังงานปฏิกิริยา (Q-value): Q = (∑mก่อน - ∑mหลัง) × 931.5 MeV
Q > 0 : คายพลังงาน (Exothermic) Q < 0 : ดูดพลังงาน (Endothermic)
