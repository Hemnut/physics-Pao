บทที่ 16 — ฟิสิกส์ ม.6

สรุปเนื้อหา: คลื่นแม่เหล็กไฟฟ้า

ทฤษฎีแมกซ์เวลล์, การแผ่คลื่น, สเปกตรัม, พลังงานโฟตอน และโพลาไรเซชัน

1. ทฤษฎีของแมกซ์เวลล์และการแผ่คลื่น

  • การกำเนิด: เกิดจากประจุไฟฟ้าเคลื่อนที่ด้วยความเร่ง (หรือความหน่วง / สั่นสะเทือน)
  • สนามแม่เหล็กที่เปลี่ยนแปลงเหนี่ยวนำให้เกิดสนามไฟฟ้า และสนามไฟฟ้าที่เปลี่ยนแปลงเหนี่ยวนำให้เกิดสนามแม่เหล็กต่อเนื่องกันไป
  • ลักษณะคลื่น: เป็น คลื่นตามขวาง (Transverse Wave) โดยสนามไฟฟ้า (E), สนามแม่เหล็ก (B) และทิศการเคลื่อนที่ (v) ตั้งฉากซึ่งกันและกันตลอดเวลา
  • ความเร็ว: ในสุญญากาศหรืออากาศมีอัตราเร็วเท่ากับความเร็วแสง c = 3 × 10⁸ m/s
c = f · λ   (อัตราเร็ว c = ความถี่ f × ความยาวคลื่น λ)

2. สเปกตรัมคลื่นแม่เหล็กไฟฟ้า

เรียงลำดับจาก ความถี่สูง (พลังงานสูง ความยาวคลื่นสั้น) ไปยัง ความต่ำ (พลังงานต่ำ ความยาวคลื่นยาว):

1. รังสีแกมมา (Gamma rays): ความถี่สูงสุด เกิดจากปฏิกิริยานิวเคลียร์ อำนาจทะลุทะลวงสูงมาก
2. รังสีเอกซ์ (X-rays): ใช้ในทางการแพทย์ ตรวจรอยร้าวโลหะ
3. รังสีอัลตราไวโอเลต (UV): จากดวงอาทิตย์ ฆ่าเชื้อโรค สร้างวิตามิน D
4. แสงขาว (Visible Light): ความยาวคลื่น ~400–700 nm (ม่วง-แดง) ตาไวที่สุด
5. รังสีอินฟราเรด (IR): คลื่นความร้อน ใช้ในรีโมท ถ่ายภาพดาวเทียม
6. ไมโครเวฟ (Microwave): ใช้ทำอาหาร เรดาร์ สื่อสารดาวเทียม
7. คลื่นวิทยุ (Radio waves): AM/FM สื่อสารระยะไกล สะท้อนชั้นไอโอโนสเฟียร์

3. พลังงานของคลื่นแม่เหล็กไฟฟ้า (โฟตอน)

พลังงานของคลื่นขึ้นกับความถึ่โดยตรง (แนวคิดของพลังค์และไอน์สไตน์):

E = h · f = (h · c) / λ

เมื่อ h คือ ค่านิจของพลังค์ = 6.626 × 10⁻³⁴ J·s

1 eV (อิเล็กตรอนโวลต์) = 1.6 × 10⁻¹⁹ J

E (in eV) ≈ 1240 / λ (in nm)

4. โพลาไรเซชันของคลื่นแม่เหล็กไฟฟ้า

  • คลื่นโพลาไรส์: คลื่นที่สนามไฟฟ้า E มีแนวการสั่นเพียงแนวเดียว
  • แผ่นโพลารอยด์: ยอมให้สนามไฟฟ้าที่มีทิศขนานกับแกนโพลาไรส์ผ่านได้เท่านั้น
  • โพลาไรเซชันโดยการสะท้อน (กฎของบรูสเตอร์): เมื่อแสงตกกระทบด้วยมุมบรูสเตอร์ θ_B แสงสะท้อนจะเป็นแสงโพลาไรส์สมบูรณ์ และแสงสะท้อนกับแสงหักเหจะทำมุมตั้งฉากกัน (90°)
tan θ_B = n₂ / n₁   (หรือ tan θ_B = n เมื่อแสงเดินทางมาจากอากาศ n₁=1)
