สรุปเจาะลึก: แสงและทัศนอุปกรณ์ (Geometrical Optics)

การสะท้อนของแสง กระจกเงาราบและทรงกลม | การหักเห กฎสเนลล์ มุมวิกฤตและสะท้อนกลับหมด | ลึกจริง-ลึกปรากฏ | ปริซึม รุ้ง มิราจ | เลนส์บาง | ตาและสายตาสั้น-ยาว | กล้องจุลทรรศน์ กล้องโทรทรรศน์ | ความสว่างและการผสมแสงสี

สูตรสำคัญประจำบท — Quick Reference

กฎการสะท้อน θ₁ = θ₂
สมการกระจก/เลนส์ 1/f = 1/s + 1/s'
กำลังขยาย m = s'/s = y'/y
กฎของสเนลล์ n₁ sin θ₁ = n₂ sin θ₂
ดัชนีหักเห n = c/v
มุมวิกฤต sin θc = n₂/n₁
ลึกจริง-ปรากฏ s'/s = n(ตา)/n(วัตถุ)
ความสว่าง E = I/R² (ลักซ์)
11.1

การสะท้อนของแสงและกระจกเงา

Law of Reflection & Spherical Mirrors

1. กระจกเงาราบ (Plane Mirror)

  • • กฎการสะท้อน: มุมตกกระทบ = มุมสะท้อน (θ₁ = θ₂)
  • • รังสีตกกระทบ เส้นปกติ และรังสีสะท้อน อยู่ในระนาบเดียวกัน
  • • ภาพที่เกิดขึ้นเป็น ภาพเสมือน หัวตั้ง อยู่หลังกระจก
  • • ระยะภาพ = ระยะวัตถุ (s' = s)
  • • ขนาดภาพ = ขนาดวัตถุ (y' = y) → กำลังขยาย m = 1
  • • เกิดการกลับข้างซ้าย-ขวา เรียกว่า ปรัศวภาควิโลม
⚠️ กระจก 2 บานทำมุม θ: จำนวนภาพ = (360°/θ) − 1

2. กระจกเงาทรงกลม (Spherical Mirrors)

  • • ความยาวโฟกัส f = R/2 เสมอ (R = รัศมีความโค้ง)
  • • กระจกเว้า (Concave): รวมแสง (f > 0) ให้ทั้งภาพจริง (หัวกลับ) และภาพเสมือน (หัวตั้ง เมื่อ s < f)
  • • กระจกนูน (Convex): กระจายแสง (f < 0) ให้เฉพาะ ภาพเสมือนหัวตั้งขนาดเล็กกว่าวัตถุ เสมอ
  • • การใช้งาน: กระจกเว้า = จานดาวเทียม, ไฟหน้ารถ | กระจกนูน = กระจกมองหลัง, กระจกทางโค้ง

สูตรคำนวณกระจกโค้งและเลนส์บาง

สมการโฟกัส 1/f = 1/s + 1/s'
กำลังขยาย (m) m = s'/s = y'/y
สูตรลัด m = f/(s − f)
ข้อตกลงเครื่องหมาย:

• กระจกเว้า / เลนส์นูน: f, R เป็น บวก (+)

• กระจกนูน / เลนส์เว้า: f, R เป็น ลบ (−)

• ภาพจริง (หัวกลับ อยู่หน้ากระจก/หลังเลนส์): s' เป็น บวก (+)

• ภาพเสมือน (หัวตั้ง อยู่หลังกระจก/หน้าเลนส์): s' เป็น ลบ (−)

• |m| > 1 = ภาพขยาย | |m| < 1=ภาพย่อ | m> 0 = หัวตั้ง | m < 0=หัวกลับ

📝 ตัวอย่างโจทย์:

วัตถุอยู่ห่างจากกระจกเว้า 30 cm กระจกมีความยาวโฟกัส 10 cm จงหาตำแหน่งภาพและกำลังขยาย

1/f = 1/s + 1/s' → 1/10 = 1/30 + 1/s' → 1/s' = 1/10 − 1/30 = 2/30 = 1/15
s' = 15 cm (บวก = ภาพจริง หัวกลับ)
m = s'/s = 15/30 = 0.5 (ขนาดครึ่งหนึ่ง หัวกลับ)
11.2

การหักเห การสะท้อนกลับหมด และลึกจริง-ปรากฏ

Refraction, Total Internal Reflection & Apparent Depth

กฎของสเนลล์และดัชนีหักเห (Snell's Law)

n₁ sin θ₁ = n₂ sin θ₂  →  sin θ₁/sin θ₂ = v₁/v₂ = λ₁/λ₂ = n₂/n₁
ดัชนีหักเห (n):
  • • n = c/v (c = 3 × 10⁸ m/s)
  • • n(อากาศ) ≈ 1.00 | n(น้ำ) ≈ 1.33 | n(แก้ว) ≈ 1.50
  • • n(เพชร) ≈ 2.42
ทิศทางการหักเห:
  • • จาก n น้อย → n มาก: หักเหเข้าหาเส้นปกติ (θ₂ < θ₁)
  • • จาก n มาก → n น้อย: หักเหออกจากเส้นปกติ (θ₂ > θ₁)
  • • ความถี่ไม่เปลี่ยน! เปลี่ยนเฉพาะ v และ λ

การสะท้อนกลับหมดและมุมวิกฤต (θc)

  • • เกิดเมื่อแสงเดินทางจากตัวกลาง n มาก → n น้อย เท่านั้น
  • • มุมวิกฤต (θc): มุมตกกระทบที่ทำให้มุมหักเห = 90°
sin θc = n₂/n₁   (เมื่อ n₁ > n₂)
  • • ถ้า θ > θc → เกิดการสะท้อนกลับหมด 100%
  • • การประยุกต์: เส้นใยนำแสง (Fiber Optics), เพชรแวววาว

ลึกจริง - ลึกปรากฏ (Apparent Depth)

ลึกปรากฏ(s') / ลึกจริง(s) = n(ตา) / n(วัตถุ)
  • • มองปลาในน้ำ (n=4/3) จากอากาศ (n=1):
    s' = s/(4/3) = (3/4)s → เห็นปลาอยู่ตื้นกว่าจริง
  • • ปลาในน้ำมองนกในอากาศ:
    s' = s×(4/3)/1 = (4/3)s → เห็นนกอยู่ไกลกว่าจริง
📝 โจทย์: ปลาอยู่ลึก 2 m มองจากอากาศ
s' = (1/(4/3)) × 2 = (3/4) × 2 = 1.5 m
11.3

ปรากฏการณ์ของแสง เลนส์บาง และสายตา

Dispersion, Rainbow, Thin Lenses & Vision

การกระจายแสงในปริซึม

แสงขาวแยกเป็น 7 สี โดย แสงสีม่วง มี λ สั้นสุด หักเหและเบี่ยงเบนมากที่สุด ส่วน แสงสีแดง มี λ ยาวสุด หักเหน้อยที่สุด

รุ้งกินน้ำ (Rainbow)

• รุ้งปฐมภูมิ: สะท้อนกลับหมด 1 ครั้งภายในเม็ดน้ำ (สีแดงอยู่บน สีม่วงอยู่ล่าง)
• รุ้งทุติยภูมิ: สะท้อนกลับหมด 2 ครั้ง (สีกลับกัน: สีม่วงอยู่บน สีแดงอยู่ล่าง อยู่สูงกว่าและจางกว่า)

มิราจ (Mirage)

อากาศใกล้พื้นถนนร้อนและเบาบาง (n น้อย) แสงจากท้องฟ้าหักเหต่อเนื่องจนเกิดการสะท้อนกลับหมดเข้าสู่ตา เห็นภาพเสมือนของท้องฟ้าคล้ายมีแอ่งน้ำบนถนน

เลนส์นูน (Converging Lens)

  • • กลางหนา ขอบบาง → รวมแสง (f > 0)
  • • s > 2f: ภาพจริง หัวกลับ เล็กกว่าวัตถุ
  • • s = 2f: ภาพจริง หัวกลับ ขนาดเท่าวัตถุ
  • • f < s < 2f: ภาพจริง หัวกลับ ใหญ่กว่าวัตถุ
  • • s = f: ไม่เกิดภาพ (รังสีขนาน)
  • • s < f: ภาพเสมือน หัวตั้ง ขนาดใหญ่กว่าวัตถุ

เลนส์เว้า (Diverging Lens)

  • • กลางบาง ขอบหนา → กระจายแสง (f < 0)
  • • ให้เฉพาะ ภาพเสมือน หัวตั้ง ขนาดเล็กกว่าวัตถุ เสมอ ไม่ว่าวัตถุจะอยู่ที่ใด
  • • กำลังของเลนส์: P = 1/f (หน่วย: ไดออปเตอร์, D)
  • • เลนส์นูน: P เป็นบวก | เลนส์เว้า: P เป็นลบ

ตาและการแก้ไขสายตาผิดปกติ

คนสายตาสั้น (Myopia):

กระบอกตายาวเกินไป หรือเลนส์ตาโค้งนูนมากเกินไป ทำให้ภาพตก ก่อนถึงเรตินา มองไกลไม่ชัด → แก้ด้วย แว่นเลนส์เว้า (กระจายแสงก่อนเข้าตา)

s = ∞, s' = −d(ไกล) → 1/f = 1/∞ + 1/(−d) = −1/d
คนสายตายาว (Hyperopia):

กระบอกตาสั้นเกินไป ทำให้ภาพตก เลยหลังเรตินา มองใกล้ไม่ชัด → แก้ด้วย แว่นเลนส์นูน (รวมแสงก่อนเข้าตา)

s = 25 cm, s' = −d(ใกล้) → 1/f = 1/25 + 1/(−d)
คนสายตาปกติ: ระยะใกล้สุด (Near Point) = 25 cm | ระยะไกลสุด (Far Point) = ∞
11.4

ทัศนอุปกรณ์ ความสว่าง และการผสมแสงสี

Optical Instruments, Illuminance & Color Addition

แว่นขยาย

เลนส์นูน 1 ตัว วางวัตถุ s < f ได้ภาพเสมือนหัวตั้งขนาดใหญ่กว่าวัตถุ

M = 25/f (กำลังขยาย)
กล้องถ่ายรูป

เลนส์นูน วางวัตถุ s > 2f ได้ภาพจริงหัวกลับย่อส่วนบนเซนเซอร์

กล้องจุลทรรศน์

เลนส์ใกล้วัตถุ (fo สั้น) สร้างภาพจริงขยาย + เลนส์ตา (fe) ขยายเป็นภาพเสมือนหัวกลับขนาดมหึมา

กล้องโทรทรรศน์

เลนส์ใกล้วัตถุ (fo ยาว) + เลนส์ตา (fe สั้น)

L ≈ fo + fe | M = fo/fe

ความสว่าง (Illuminance: E)

E = F/A = I/R²  (ลักซ์, lux = lm/m²)
  • • F: ฟลักซ์ส่องสว่าง (ลูเมน, lm)
  • • I: ความเข้มแห่งการส่องสว่าง (แคนเดลา, cd)
  • • R: ระยะห่างตั้งฉากจากหลอดไฟถึงพื้นผิว (m)
  • • แสงตกเฉียงมุม θ: E = I cos θ/R²

แสงสีปฐมภูมิและสีเติมเต็ม

• แสงสีปฐมภูมิ: แดง (R) + เขียว (G) + น้ำเงิน (B)
• แดง + เขียว = เหลือง | แดง + น้ำเงิน = แดงม่วง (Magenta) | เขียว + น้ำเงิน = น้ำเงินเขียว (Cyan)
• ทั้ง 3 สีปฐมภูมิรวมกัน = แสงขาว
• สีเติมเต็ม: แดง+Cyan, เขียว+Magenta, น้ำเงิน+เหลือง → ได้แสงขาว

สีของวัตถุ: วัตถุ สะท้อน แสงสีที่ตรงกับสีของตัวเอง และ ดูดกลืน แสงสีอื่น
