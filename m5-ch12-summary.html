แสงเชิงฟิสิกส์ (Physical Optics)

1. การแทรกสอดผ่านสลิตคู่ (Double Slit Interference)

เกิดแถบสว่างและแถบมืดสลับกันบนฉากอย่างสมมาตร

แถบสว่าง (Bright Fringe: A_n)
d · sinθ =
d · x D
= n · λ
แถบมืด (Dark Fringe: N_n)
d · sinθ =
d · x D
= (n - ½) · λ

2. การเลี้ยวเบนสลิตเดี่ยว (Single Slit)

แถบสว่างกลางจะกว้างและสว่างที่สุด แถบมืดคำนวณจาก:

d · sinθ =
d · x D
= n · λ   (แถบมืด)

3. เกรตติง (Diffraction Grating)

มี N ช่อง/cm ระยะห่างช่อง d = (1/N) cm แถบสว่างคมชัดมาก

d · sinθ = n · λ   (n = 1, 2, 3...)
