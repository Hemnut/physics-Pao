สรุปเนื้อหา: แสงเชิงฟิสิกส์ (Physical Optics)

การแทรกสอดของแสงผ่านสลิตคู่ (Young's Slit) | การเลี้ยวเบนของแสงผ่านสลิตเดี่ยว | เกรตติง (Diffraction Grating) & สเปกตรัม | การกระเจิงของแสงในชั้นบรรยากาศ

12.1

การแทรกสอดของแสงผ่านสลิตคู่ (Double Slit)

Young's Double-Slit Experiment

เมื่อฉายแสงอาพันธ์ความยาวคลื่นเดียว ($\lambda$) ตกตั้งฉากกับแผ่นสลิตคู่ที่มีระยะห่างระหว่างช่องเป็น $d$ แสงที่ผ่านช่องแคบทั้งสองจะเกิดการแทรกสอด ปรากฏเป็นริ้วแถบสว่างและแถบมืดสลับกันอย่างสม่ำเสมอบนฉากที่อยู่ห่างออกไปเป็นระยะ $D$

แถบสว่าง (Bright Fringes / ปฏิบัพ Aₙ) แทรกสอดเสริม

ผลต่างทางเดินของแสงเป็นจำนวนเต็มเท่าของความยาวคลื่น:

|S₁P − S₂P| = nλ
d sin θ = nλ  ≈  d · (x / D) = nλ
x = nλD / d
(n = 0 คือแถบสว่างกลาง A₀, n = 1, 2, 3...)
แถบมืด (Dark Fringes / บัพ Nₙ) แทรกสอดหักล้าง

ผลต่างทางเดินของแสงเป็นครึ่งหนึ่งของความยาวคลื่น:

|S₁P − S₂P| = (n − ½)λ
d sin θ = (n − ½)λ  ≈  d · (x / D) = (n − ½)λ
x = (n − ½)λD / d
(n = 1 คือแถบมืดแรก N₁, n = 2, 3...)
ระยะห่างระหว่างแถบสว่าง 2 แถบที่ติดกัน (Fringe Width: Δx):

แถบสว่างของการแทรกสอดสลิตคู่จะมีระยะห่างเท่าๆ กันตลอด

Δx = λ · D / d
12.2

การเลี้ยวเบนของแสงผ่านสลิตเดี่ยว (Single Slit)

Single Slit Diffraction Pattern

เมื่อแสงผ่านช่องแคบเดี่ยวกว้าง $a$ หรือ $d$ แสงจะเลี้ยวเบนและแทรกสอดกันเอง ทำให้เกิด แถบสว่างกลางที่มีขนาดกว้างมากและสว่างที่สุด โดยมีแถบมืดและแถบสว่างข้างๆ ที่มีความสว่างลดลงอย่างรวดเร็ว

สมการตำแหน่งแถบมืด (Dark Fringes)

ในการคำนวณสลิตเดี่ยว เราจะคิดที่ตำแหน่งแถบมืด:

d sin θ = nλ
d · (x / D) = nλ  →  x = nλD / d
(n = 1, 2, 3... คือแถบมืดลำดับที่ 1, 2, 3...)

ความกว้างของแถบสว่างกลาง (Central Fringe)

ระยะระหว่างแถบมืดแรกทั้งสองข้าง ($N_1$ ด้านซ้ายถึง $N_1$ ด้านขวา):

ความกว้างแถบสว่างกลาง = 2x₁ = 2λD / d
แถบสว่างกลางจะกว้างเป็น 2 เท่าของแถบสว่างข้างเคียง
12.3

เกรตติงและสเปกตรัมของแสง (Diffraction Grating)

Gratings, Spectral Lines & Max Orders

เกรตติงคือแผ่นทึบแสงที่มีช่องแคบจำนวนมากขนานกันอย่างสม่ำเสมอ เช่น 1,000 ถึง 10,000 ช่องต่อเซนติเมตร ทำให้ริ้วแถบสว่างมีความคมชัดและแยกสเปกตรัมของแสงสีต่างๆ ได้ละเอียดมาก

ระยะห่างช่องเกรตติง (d) & แถบสว่าง

d = ความยาวเกรตติง / จำนวนช่อง = 1 / N

สมการแถบสว่างของการแทรกสอดผ่านเกรตติง:

d sin θ = nλ   (n = 0, 1, 2, 3...)

การซ้อนทับกัน & จำนวนแถบสว่างสูงสุด

  • • การซ้อนทับกันของสเปกตรัม: แถบสว่างสีที่ 1 ลำดับ $n_1$ ซ้อนทับกับสีที่ 2 ลำดับ $n_2$ เมื่อ: n₁ λ₁ = n₂ λ₂
  • • จำนวนแถบสว่างสูงสุด: คิดที่มุมเบี่ยงเบนมากสุด $\theta = 90^\circ$ ($\sin 90^\circ = 1$): n_{max} \le d / \lambda จำนวนแถบสว่างทั้งหมดที่มองเห็นได้ = $2n_{max} + 1$ (รวมแถบกลาง $n=0$)
12.4

การกระเจิงของแสง (Rayleigh Scattering)

Why the Sky is Blue & Sunsets are Red

เมื่อแสงอาทิตย์ส่องผ่านบรรยากาศโลก แสงจะตกกระทบโมเลกุลของก๊าซในอากาศ ทำให้อิเล็กตรอนในโมเลกุลดูดกลืนและปลดปล่อยคลื่นแสงออกมาในทุกทิศทาง โดยอัตราการกระเจิงจะแปรผกผันกับความยาวคลื่นยกกำลังสี่: การกระเจิง $\propto \frac{1}{\lambda^4}$ (แสง $\lambda$ สั้นกระเจิงได้ดีกว่า $\lambda$ ยาว)

ทำไมท้องฟ้าเวลากลางวันเป็นสีฟ้า?

แสงสีม่วงและสีน้ำเงินมีความยาวคลื่นสั้น จึง กระเจิงได้ดีกว่าแสงสีแดงมาก และกระจายไปทั่วท้องฟ้า ประกอบกับสายตาของมนุษย์มีความไวต่อแสงสีน้ำเงินมากกว่าแสงสีม่วง เราจึงมองเห็นท้องฟ้าเป็นสีฟ้าครามสดใส

ทำไมท้องฟ้าตอนเช้าและตอนเย็นเป็นสีส้มแดง?

ขณะดวงอาทิตย์อยู่ใกล้ขอบฟ้า แสงอาทิตย์ต้องเดินทางผ่านชั้นบรรยากาศเป็นระยะทางที่ยาวไกลมาก แสงสีม่วงและสีน้ำเงินถูกกระเจิงออกไปหมดก่อนจะถึงตาเรา เหลือเพียง แสงสีแดงและสีส้ม ซึ่งมีความยาวคลื่นยาวและกระเจิงน้อยที่สุด เดินทางตรงเข้าสู่ตาเราได้
